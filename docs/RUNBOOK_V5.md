# Reproduce network investigation on a constrained workstation

Python 3.11+ is enough for the core. Loki/Grafana and virtual machines are unnecessary for these exercises. Use fresh output paths and keep original captures separate from the report. Packet contents, URLs and business context can contain secrets; do not publish a private capture just because the report is HTML.

## Constructed end-to-end exercise

From the repository root:

```powershell
python scripts/validate_network.py --run-id practice-network-01 --out output/practice-network-01-validation.json
python -m http.server 8767 --bind 127.0.0.1 --directory output/network/practice-network-01
```

Open `http://127.0.0.1:8767/constructed-report/index.html`. The run builds 17 packet records and two fictional Sysmon network events, then approves their exact source hashes before proposing endpoint candidates. The three heuristics must remain unassessed, and two endpoint candidates must remain visible. No socket traffic or attack command is generated by the fixture builder.

The standard-library HTTP server is only a static viewer. Stop it with Ctrl+C. It has no application accounts and must stay on loopback. The older casebook/operations viewers remain separate.

## Public captures and independent decoding

```powershell
python scripts/validate_network.py --public --run-id public-network-01 --out output/public-network-01-validation.json
```

The downloader verifies both capture sizes/hashes before use. An altered cached file fails; preserve it for investigation and choose a deliberate replacement after checking acquisition. Do not silently change the catalog to make an unexpected download pass.

Optional independent validation installs a decoder into an ignored folder, leaving the core dependency-free:

```powershell
python -m pip install --target output/validation-deps --require-hashes -r requirements-network-validation.txt
python scripts/validate_network.py --public --independent --dependencies-dir output/validation-deps --run-id independent-network-01 --out output/independent-network-01-validation.json
```

The expected public results are HTTP: 43 packets/3 flows/2 DNS messages/2 HTTP requests; DNS: 38 packets/8 flows/38 DNS messages. They are two independent historical samples. An empty heuristic list is not a complete benign assessment.

## Inspect your own approved local capture

```powershell
python -m soclab network --capture data/local/approved.pcap --out output/approved-network-review
```

Classic IPv4 PCAP is required. PCAPNG is rejected explicitly; use a trusted packet tool to convert it and retain the original plus conversion provenance. IPv6 and fragmented traffic remain coverage gaps. Do not claim this parser replaces Wireshark.

For endpoint pivots, provide both `--endpoint-db` and `--scope`. The scope JSON must contain `capture_sha256`, `endpoint_source_sha256` (all approved imported-source hashes) and `collection_reason`. The constructed workspace contains a working example. For business context, use `--context`; copy the generated schema and supply verified owner/service information rather than treating the example inventory as discovered facts.

## Extract original bytes for a selected frame

```powershell
python -m soclab network --capture data/raw/network/http.cap --packet 4 --source-sha256 25a72bdf10339f2c29916920c8b9501d294923108de8f29b19aba7cc001ab60d --out output/http-packet-4.json
```

The output carries the original offset, frame/source hashes and hexadecimal captured bytes. Inspect it as data; do not execute embedded commands or visit captured URLs. Retain packet extraction alongside the unchanged original PCAP.
